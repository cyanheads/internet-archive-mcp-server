# 0.2.0 — 2026-09-24

## Added

- **`ia_get_item` `max_files` / `file_offset` / `format` inputs** ([#10](https://github.com/cyanheads/internet-archive-mcp-server/issues/10)) — `max_files` (1–500, default 50) and `file_offset` (default 0) page the manifest; `format` keeps one file type (exact, case-insensitive, e.g. `DjVuTXT`) before paging. `file_count` still reports the full manifest.
- **`ia_get_item` enrichment** — `truncated` with the next `file_offset` when files remain, `totalCount` for a `format` match, and a `notice` listing the item's formats when `format` matches nothing.

## Changed

- **`ia_get_item` returns one page of files by default** ([#10](https://github.com/cyanheads/internet-archive-mcp-server/issues/10)) — items with more than 50 files now return the first 50; pass `file_offset` or `format` to reach the rest. `ia_get_text` still scans the full manifest, and the `ia://item/{identifier}` resource is unchanged.
- **`ia_get_text` description** points at `ia_get_item` with `format: "DjVuTXT"` to confirm a text file exists.
- **README** and `docs/design.md` document the paging inputs.

## Fixed

- **`ia_get_item` multi-language items** ([#6](https://github.com/cyanheads/internet-archive-mcp-server/issues/6)) — `language` is now `string | string[]`, so items whose metadata lists several languages no longer fail output validation; `content[]` joins them with `, `.
- **Service-thrown errors forward the declared recovery hint** ([#18](https://github.com/cyanheads/internet-archive-mcp-server/issues/18)) — `item_not_found`, `no_text_file`, `no_snapshot_available`, and `cdx_unavailable` now carry `data.recovery.hint`, resolved from the calling tool's or resource's own contract.
- **Example identifier** ([#9](https://github.com/cyanheads/internet-archive-mcp-server/issues/9)) — `ia_get_item`, `ia_get_text`, and `ia://item/{identifier}` use `prideprejudice00aust` in place of the dark `pg1342` and the missing `UndergraduateMathematics`; the resource's `list()` entry follows.
- **`openWorldHint: true`** on `ia_find_snapshots`, `ia_get_snapshot`, `ia_get_item`, and `ia_get_text` ([#22](https://github.com/cyanheads/internet-archive-mcp-server/issues/22)), matching the external Internet Archive APIs they call.
