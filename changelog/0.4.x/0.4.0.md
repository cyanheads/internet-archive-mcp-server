# 0.4.0 — 2026-10-12

## Added

- **`archive_unavailable`** ([#33](https://github.com/cyanheads/internet-archive-mcp-server/issues/33)) — Metadata API and text download failures on `ia_get_item`, `ia_get_text`, and `ia://item/{identifier}`: 5xx, 429 (with a wait hint), other 4xx, timeouts, network errors, unreadable responses.
- **`ia_search_items` errors** ([#29](https://github.com/cyanheads/internet-archive-mcp-server/issues/29), [#39](https://github.com/cyanheads/internet-archive-mcp-server/issues/39)) — `invalid_query` (query syntax, unquoted URL, over-length query, bad sort), `search_unavailable` (failures, 429, timeouts, network errors), `rows_over_cap`, and `page_limit_exceeded` (`page × rows` past 10,000). Error bodies Advanced Search returns with HTTP 200 no longer read as "No items matched".
- **`ia_get_text` `source_file_bytes`** — the text file's size in bytes from the item manifest.
- **`ia_search_items` `creator_count`** ([#30](https://github.com/cyanheads/internet-archive-mcp-server/issues/30)) — set when `creator` lists only the first 10 names.
- **Hosted instance** — `https://internet-archive.caseyjhand.com/mcp` in `server.json` `remotes` and the README.

## Changed

- **`ia_get_text` no longer returns `total_chars`** ([#33](https://github.com/cyanheads/internet-archive-mcp-server/issues/33)) — read `has_more` for further text; `source_file_bytes` replaces the size signal.
- **`ia_search_items` `title` and `date`** ([#36](https://github.com/cyanheads/internet-archive-mcp-server/issues/36)) — `string | string[]`; a record carrying a list no longer fails the page.
- **Upstream failures changed codes and reasons** ([#31](https://github.com/cyanheads/internet-archive-mcp-server/issues/31)) — Wayback timeouts, network errors, and other 4xx are `cdx_unavailable`, `availability_unavailable`, or `content_fetch_failed`; an archived error capture or a 403/410/451 refusal is `no_snapshot_available`. A 429, another 4xx, or a timeout is answered after one request.
- **Over-cap values are served at the cap** ([#35](https://github.com/cyanheads/internet-archive-mcp-server/issues/35)) — `ia_search_items` `rows` on page 1 (up to 10,000 → 200), `ia_get_item` `max_files` (up to 300,000 → 500), `ia_find_snapshots` `limit` (up to 150,000 → 10,000), each with `truncated` and a `notice` naming the continuation.
- **`ia_search_items` results** ([#30](https://github.com/cyanheads/internet-archive-mcp-server/issues/30)) — `collection` leaves out `fav-` lists, `creator` carries at most 10 names, ties under the sort are ordered by `identifier`, and `query` is capped at 2,047 characters.
- **`IA_REQUEST_TIMEOUT_MS` and `IA_MAX_SNAPSHOT_CHARS`** must be positive integers; anything else fails startup.

## Security

- **`ia_get_text` page-bounded reads** ([#33](https://github.com/cyanheads/internet-archive-mcp-server/issues/33)) — the upstream read stops at the requested page, so per-call memory and upstream transfer are bounded by the page size; `max_chars` is capped at `IA_MAX_SNAPSHOT_CHARS`, and a larger value is served at it with a `notice`.
