# 0.4.1 — 2026-10-24

## Fixed

- **`ia_get_text` continuation** resumes sequential pages from validated byte checkpoints with UTF-16 offsets; expiring tenant-scoped cursors retain no document text, and unavailable validators or storage leave offset paging available with a notice. ([#37](https://github.com/cyanheads/internet-archive-mcp-server/issues/37))
- **`ia_find_snapshots` paging** retains capture boundaries for exact URLs with `timestamp:N` collapse; cursors preserve filters and allow page-size changes, while legacy and wildcard continuations disclose possible omissions. ([#38](https://github.com/cyanheads/internet-archive-mcp-server/issues/38))
- **`ia_search_items` date bounds** expand `YYYY` and `YYYY-MM` to inclusive Gregorian boundaries and reject invalid dates before requesting Advanced Search. ([#40](https://github.com/cyanheads/internet-archive-mcp-server/issues/40))
- **Markdown output** preserves literal upstream titles, metadata and document text, and renders URL fields as usable links.

## Changed

- **Hosted setup examples** distinguish Claude Code, Cline, Cursor and Claude Desktop configuration.
- **Build tooling** aligns Bun images and the package manager from 1.4.3 → 1.4.4, refreshes framework guidance, and classifies mixed-version audit findings against the installed direct dependency.
