# 0.3.1 — 2026-10-07

## Changed

- **Tool errors** include request IDs (mcp-ts-core 0.13.10); framework-added stack, context, and root-cause details stay off the wire (0.13.7, 0.13.8, 0.13.13).
- **Container builds** use Bun 1.4.0 → 1.4.2, compile and cross-install production dependencies on the native build platform, install OpenTelemetry at the framework's peer ranges, and copy dependencies into the runtime image without musl-only bindings.
- **Development tooling** syncs framework documentation, skills, definition/packaging gates, release-tag validation, environment examples, and per-language CodeQL categories.

## Fixed

- **MCP Registry launches** use the npm package bin through `npx`; the HTTP entry fixes `MCP_TRANSPORT_TYPE=http` instead of passing npm-script arguments.
- **Package exclusions** keep built MCPB files out of the npm tarball and cache/log files out of the bundle; Docker contexts exclude all environment files and registry credentials.
