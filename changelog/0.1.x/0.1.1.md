# 0.1.1 — 2026-06-05

Initial public release of `@cyanheads/internet-archive-mcp-server`. Provides 5 MCP tools and 1 resource over the [Internet Archive Wayback Machine](https://web.archive.org/) (CDX and Availability APIs) and [IA library](https://archive.org/) (Advanced Search and Metadata APIs):

- **`ia_find_snapshots`** — discover Wayback Machine captures for any URL; closest-snapshot or full CDX history with date/status/MIME filters and resume-key pagination
- **`ia_get_snapshot`** — fetch archived page content at a specific timestamp; strips HTML to readable text and returns the canonical replay URL
- **`ia_search_items`** — full-text search across 40M+ IA items with mediatype, collection, creator, date-range, and language filters
- **`ia_get_item`** — retrieve full metadata and the file manifest for an Archive item by identifier
- **`ia_get_text`** — retrieve OCR text from a text item with length-aware truncation and `char_offset` paging
- **`ia://item/{identifier}`** — resource exposing metadata snapshot for any Archive item

## Added

- **`ia_find_snapshots`** — Wayback CDX + Availability API tool; supports `closest` and `history` modes, collapse, date/status/MIME filters, and resume-key pagination
- **`ia_get_snapshot`** — Wayback replay fetch tool; HTML-to-text extraction capped at `IA_MAX_SNAPSHOT_CHARS` (default 50 000 chars)
- **`ia_search_items`** — IA Advanced Search (Solr) tool with mediatype, collection, creator, date range, language, and sort filters
- **`ia_get_item`** — IA Metadata API tool returning title, creator, description, subjects, collections, license, and per-file download URLs
- **`ia_get_text`** — IA file-fetch tool for DjVuTXT/plain-text items with `char_offset` continuation pointer for large documents
- **`ia://item/{identifier}`** — MCP resource for Archive item metadata snapshots
- **`WaybackService`**, **`ArchiveSearchService`**, **`ArchiveMetadataService`** — three domain services covering the full IA API surface
- **`server-config.ts`** — `IA_USER_AGENT`, `IA_REQUEST_TIMEOUT_MS`, `IA_MAX_SNAPSHOT_CHARS` env-var configuration
- **`bunfig.toml`** — Bun config for consistent installs across environments

## Security

- **Wayback SSRF guard** — `ia_find_snapshots` (closest mode) validates the Availability API response URL starts with `https://web.archive.org/` before returning it; rejects any unexpected host
- **Solr query injection prevention** — `ia_search_items` quotes all filter values and escapes backslashes and double-quotes via `solrEscape()`; date-range boundaries are validated against `YYYY-MM-DD` before embedding in range queries
- **Output cap** — `ia_get_snapshot` text is sliced to `IA_MAX_SNAPSHOT_CHARS` (default 50 000) to prevent unbounded response sizes; `status_filter` restricted to 3-digit numeric codes via Zod schema
