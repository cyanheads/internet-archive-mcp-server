# 0.1.5 — 2026-09-19

## Added

- **CodeQL workflow** — first static-analysis workflow for this repo (`.github/workflows/codeql.yml`), enabled by turning off the repo's CodeQL default setup. Two open alerts against `wayback-service.ts` are pre-existing and already tracked on [#8](https://github.com/cyanheads/internet-archive-mcp-server/issues/8).

## Changed

- **`MCP_SESSION_MODE` defaults to `stateless` everywhere** ([#16](https://github.com/cyanheads/internet-archive-mcp-server/issues/16)) — `createApp({ sessionMode: 'stateless' })` declares the posture in `src/index.ts`, and `.env.example`'s default is now active rather than commented out, matching the `Dockerfile`. `MCP_SESSION_MODE` wins whenever it carries a meaningful value; `createApp({ sessionMode })` seeds it otherwise.
- **Error contracts gain `severity`/`thrownBy` metadata** across the tool and resource `errors[]` declarations (mcp-ts-core 0.13.5, 0.13.6).
- **Framework [`@cyanheads/mcp-ts-core`](https://www.npmjs.com/package/@cyanheads/mcp-ts-core) ^0.12.3 → ^0.13.6** — Bun engines floor raised `>=1.3.0` → `>=1.4.0` (0.12.9); the skill tree moves to `framework-skills/`, since a plugin host auto-loads a root `skills/` and was handing these development skills to every installing agent (0.13.0); `createApp({ sessionMode })` (0.13.1).
- **README** restructured into a compact tools/resources overview plus a per-primitive capability reference.
- GitHub community health files, issue templates, and plugin manifest metadata resynced from the framework's templates.

## Fixed

- **`ia_find_snapshots` history-mode pagination** ([#17](https://github.com/cyanheads/internet-archive-mcp-server/issues/17)) — the CDX trailer's all-empty separator row was matched only as `[""]`; CDX actually emits `[]`, so the guard never fired and both trailer rows were returned as fabricated capture records with `resume_key` absent. The separator now matches any all-empty row.
- **`ia_get_snapshot` content-fetch failures** — a `ServiceUnavailable` from the archived-page fetch now maps to the declared `content_fetch_failed` contract instead of propagating raw, so callers receive the recovery hint.
