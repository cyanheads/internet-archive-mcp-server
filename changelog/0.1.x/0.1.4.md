# 0.1.4 — 2026-08-21

## Added

- **Community health files** — `.github/SECURITY.md` (disclosure policy), `CONTRIBUTING.md`, and `CODE_OF_CONDUCT.md`.
- **Test suites** — smoke (`tests/smoke/`), integration contract (`tests/integration/`), and fuzz (`tests/fuzz/`) lanes wired into `vitest.config.ts`, service-level tests for the download contract (`tests/services/`), a `test:coverage` script backed by `@vitest/coverage-istanbul`, and `.gitattributes` for line-ending normalization.

## Changed

- **Framework [`@cyanheads/mcp-ts-core`](https://www.npmjs.com/package/@cyanheads/mcp-ts-core) ^0.10.6 → ^0.12.3** — adopts MCP SDK v2: every endpoint serves protocol revision 2026-07-28 alongside the 2025 era; tool inputs are strict, so an unrecognized argument key is rejected by name instead of stripped; and the advertised output schema declares the error envelope, so clients that validate `structuredContent` no longer reject error results with `-32602`.
- **Supply-chain guard** — `bunfig.toml` holds freshly published versions for 3 days before install (`minimumReleaseAge`, framework excluded so its releases adopt same-day) and runs the Socket security scanner on every install.
- **Docker image** — base moved to Bun 1.4.0; multi-arch builds run the compile stage natively on the builder's arch via `--platform=$BUILDPLATFORM` (Bun 1.4's JSC aborts under QEMU); BuildKit cache mounts speed installs; the production stage omits the framework's optional peer tiers.
- **TypeScript 7 toolchain** — typecheck and build run on `typescript` ^7.0.2, with Biome ^2.5.9 and Vitest ^4.1.11.
- **devcheck gates** — floating dependency specifiers (`latest`, `*`, dist-tags) now fail the build, and plugin marketplace manifests are validated (unscoped display names, full npm name in install args).

## Fixed

- **`ia_get_text` restricted-item downloads** ([#7](https://github.com/cyanheads/internet-archive-mcp-server/issues/7), [#12](https://github.com/cyanheads/internet-archive-mcp-server/issues/12)) — the Internet Archive answers both 401 (login-required) and 403 (limited collection) for restricted downloads; both now remap to the declared `download_forbidden` contract instead of surfacing a raw upstream error, and the recovery hint reaches `data.recovery.hint` and its `content[]` mirror.
