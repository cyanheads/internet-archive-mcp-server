# 0.1.3 — 2026-06-12

## Added

- **`ia_find_snapshots` truncation enrichment** — history mode now emits `ctx.enrich.truncated({ shown, cap })` when the returned record count hits `limit`, surfacing `truncated` / `shown` / `cap` in the response so callers know to page further.
- **`scripts/clean-mcpb.ts`** — post-pack bundle cleaner wired into `bundle`; runs `mcpb clean` (dev-dependency prune) then strips dependency-shipped agent docs (`node_modules/**` `skills/`, `.claude/`, `.agents/`, `SKILL.md`) that root-anchored `.mcpbignore` patterns cannot reach, and asserts zero remain.
- **`lint:packaging` post-bundle content check** — fails when a built `.mcpb` under `dist/` contains agent-doc entries; the `AGENT_DOC_ENTRY` pattern is kept in sync with `clean-mcpb.ts`.
- **Framework antipattern rule `coerce-boolean-env-flag`** — `check-framework-antipatterns.ts` now flags `z.coerce.boolean()` in `src/` (including consumer config), since `Boolean("false")` is `true` and the flag can't be disabled via env; comment-line matches are skipped.
- **Dockerfile `HEALTHCHECK`** — bun-native `fetch` against `/healthz`, no curl/wget dependency; `org.opencontainers.image.version` label populated from a new `APP_VERSION` build arg.

## Changed

- **`createApp()` identity** — `name` and `title` set explicitly to `internet-archive-mcp-server` (the unscoped repo name) so the `initialize` response and `/.well-known/mcp.json` manifest display the machine name rather than the npm scope.
- **`.mcpbignore`** — `.claude/`, `.agents/`, `skills/` patterns root-anchored (`/.claude/` etc.) so they exclude only the project's own top-level trees.
- **`@cyanheads/mcp-ts-core`** `^0.9.21` → `^0.10.6`
- **`@biomejs/biome`** `^2.4.16` → `^2.5.0`
- **`@types/node`** `^25.9.2` → `^25.9.3`
- **Vendored skills** — synced to the installed framework version across `skills/`, `.claude/skills/`, `.agents/skills/`.
