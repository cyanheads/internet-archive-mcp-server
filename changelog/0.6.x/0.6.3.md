# 0.6.3 — 2026-11-26

## Changed

- **`ia_get_text`** reads `/metadata/{identifier}/files` instead of the whole item record, on the first page and every continuation ([#73](https://github.com/cyanheads/internet-archive-mcp-server/issues/73)). `micro_IA40244325_0031` has a 21,176,700-byte record and a 6,460-byte file list. An unknown or dark item, which that path answers with HTTP 200 and an `error` body, fails as `item_not_found`.
- **`@cyanheads/mcp-ts-core`** ^0.13.22 → ^0.13.23: `fetchWithTimeout` follows redirects itself, up to 127 hops. Dev dependencies: `vitest` and `@vitest/coverage-istanbul` ^5.1.1 → ^5.1.2, `@biomejs/biome` ^2.6.8 → ^2.6.9, `fast-check` ^4.10.3 → ^4.11.0, `ignore` ^7.0.16 → ^7.0.17, `tsc-alias` ^1.9.10 → ^1.9.11, `@types/node` ^26.6.6 → ^26.6.10.

## Fixed

- **Dot-segment identifiers** ([#73](https://github.com/cyanheads/internet-archive-mcp-server/issues/73)): an identifier that names no item once its dot segments resolve fails as `item_not_found` on `ia_get_item`, `ia_get_text`, and `ia://item`, before any request. That covers `.`, `..`, `../`, `a/..`, `./`, and `../a`, including from an item URL such as `https://archive.org/details/..%2F`; `a/../b` and `./a-volume`, which resolve to an item, are still read as sent. 0.6.2 read `.` as the record of an item named `files` and `..` as a home page.
- **Refused redirect chains**: a redirect chain the framework refuses, a loop past 127 hops or a hop to a non-HTTP URL, fails under each tool's declared unavailable reason. The message names what the upstream did (`… redirected more than 127 times.`, `… redirected to a URL that is not HTTP or HTTPS.`), in place of the framework's hint to request another URL. The CDX closest-capture fallback, after an empty Availability answer, names a redirect, a timeout (with the fallback's own limit), or a network error the same way.
- **Text-level tags** (`ia_get_snapshot`, `ia_get_item`, `ia://item`) ([#75](https://github.com/cyanheads/internet-archive-mcp-server/issues/75)): the tags of text-level elements (`a`, `b`, `i`, `span`, `sup`, …) add no space in snapshot text and item descriptions, so punctuation stays on its link and a word that changes style partway stays whole. A link and the element beside it keep one space between two words outside CJK text. On a page with inline markup `total_chars` and `char_offset` change; restart a read at `char_offset` 0.
- **Hidden content** (`ia_get_snapshot`) ([#76](https://github.com/cyanheads/internet-archive-mcp-server/issues/76)): snapshot text leaves out the content of a phrasing element its own `hidden` attribute or inline `display:none` hides, which 0.6.2 read as visible text, and `links` lists no link inside it. The inline style is read as CSS tokenizes it, and nothing hidden opens inside `textarea`, `title`, or `iframe`-type elements.
- **Templates** (`ia_get_snapshot`): snapshot text leaves out a `<template>`'s content, unless the template declares a shadow root, and reads no link or `<base href>` inside it.
