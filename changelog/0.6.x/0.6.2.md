# 0.6.2 — 2026-11-22

## Added

- **`ia_get_snapshot` `include_links`** adds `links` (`{ text, url }`, each http(s) target once, on the page its first occurrence starts in) and `total_links`; the next-page notice names the option ([#67](https://github.com/cyanheads/internet-archive-mcp-server/issues/67)). A link's `text` is its first non-empty label, which can come from a later anchor than the link's position, and the one page of an empty text lists that page's image-only links.
- **`ia_get_text` `find`** starts the page at the first match of a literal phrase (at most 500 characters, case-insensitive, a whitespace run matching any run) at or after `char_offset` or the continuation's position, and returns `match_offset`; a miss returns empty `text` and a notice ([#70](https://github.com/cyanheads/internet-archive-mcp-server/issues/70)).
- **`find_incomplete`** (`Timeout`): a `find` search that would outrun the download's request timeout or the call deadline stops first, and a first match found past a whitespace run longer than the text a call holds fails the same way, naming the match's `char_offset` ([#70](https://github.com/cyanheads/internet-archive-mcp-server/issues/70)). A stopped search resumes by `next_continuation`: the hint names the continuation alone when one was stored, and `char_offset` only when none could be stored and the search advanced (that call reads the file from its first byte).
- **A `find` search that cannot get past its start**, with no cursor that skips the bytes before it, fails as `archive_unavailable` after one download, as a read without `find` fails when its download cannot reach `char_offset`.
- **`ia_find_snapshots` `collapse`** accepts `digest` (the first capture in range and each capture whose digest differs from the one before) and `urlkey` (one row per URL); prefix queries are documented: a `url` ending in `*` lists every URL under the prefix, a leading `*.` a domain ([#69](https://github.com/cyanheads/internet-archive-mcp-server/issues/69)). A `*` in the middle of a `url` is read literally and pages by cursor. A `digest` cursor counts the rows already returned at its second, because dropping by the first row carrying the digest loops when digests run A, B, A within one second.
- **`ia_get_item` file `title`, `track`, and `length`**, and item `runtime`, as catalogued; `ia://item/{identifier}` returns `runtime` too ([#68](https://github.com/cyanheads/internet-archive-mcp-server/issues/68)).
- **`publicdate`** on `ia_search_items` rows and `ia_get_item`, and **`addeddate`** on `ia_get_item`; `ia://item/{identifier}` returns both. The `date_from` and `date_to` descriptions say they match the publication `date` only ([#71](https://github.com/cyanheads/internet-archive-mcp-server/issues/71)).

## Changed

- **HTML capture text in lines** (`ia_get_snapshot`): each block element and `<br>` starts a line, table cells in a row are tab-separated (empty cells included), and `<pre>` text keeps its spacing ([#66](https://github.com/cyanheads/internet-archive-mcp-server/issues/66)). A page keeps its previous length and offsets only with no `<pre>`, no blank line, and no empty cell before a non-empty cell in its row; otherwise restart a read at `char_offset` 0.
- **An empty history** (`ia_find_snapshots`) is `snapshots: []` with a `notice` saying why; the `no_snapshots` failure is removed ([#72](https://github.com/cyanheads/internet-archive-mcp-server/issues/72)).

## Fixed

- **`ia_get_item` list-valued `rights`, `licenseurl`, and `volume`** no longer fail the call: all six fields declared a string (these three, `mediatype`, `openlibrary_edition`, `openlibrary_work`) accept a string or a list, and `content[]` renders a list one item per value, each license a link ([#65](https://github.com/cyanheads/internet-archive-mcp-server/issues/65)).
- **`ia_find_snapshots` paging on an exact URL**: every `collapse` value pages through server cursors, so `timestamp:0` and `timestamp:15`–`99` no longer send 0.6.1's request. 0.6.1 skipped a capture at each later page boundary there, and under `timestamp:0` at `limit` 1 returned a key whose next page was empty ([#69](https://github.com/cyanheads/internet-archive-mcp-server/issues/69)).
- **`ia_search_items`** leaves a row field out when Advanced Search sends it as something other than a string or a list of strings, instead of failing the whole page.
- **An Advanced Search answer whose `docs` are not a list of records** is `search_unavailable` after the retry loop, where it was an internal error carrying runtime text.
- **`ia_get_item`** reads each file manifest entry field by field, so a malformed `name`, `format`, `size`, or `md5` no longer fails the call.
- **A license value that is not a web URL** rendered twice in `content[]` (`CC0 1.0 (CC0 1.0)`); it now renders once.
- **A CDX row holding a non-string cell** answers `cdx_unavailable` instead of an internal error.
